---
name: process-ownership
description: Track an ongoing responsibility and follow it through to completion.
---

1. Establish what done means. Ask only for missing information that changes the work.
2. Use a stable commitment ID. Save the objective, source, and next concrete action.
3. Do useful authorized work with the available tools. Check actual results.
4. Save meaningful progress. Use clock and an explicit wakeAt when waiting.
5. On wake-up, inspect current state before acting. Update the same commitment.
6. Notify the owner about useful findings, blockers, completion, or promised check-ins.
7. Mark done only with evidence. Stop scheduling checks once done or cancelled.

Schoolwork and email triage use this same procedure. Do not claim assignments are
finished just because they were put on a calendar or their email was archived.

For recurring work, use routine rather than repeatedly setting commitment wakeAt.
The routine owns its next run; the commitment tracks the work and its progress.
